# Video Demonstration Guide

Record a 2–4 minute screen recording.

## Suggested sequence

1. Show the GitHub repository structure.
2. Open `README.md` briefly.
3. Start the application with `streamlit run app.py`.
4. Show KPI cards.
5. Select a country.
6. Change guest capacity and price filters.
7. Show Overview charts.
8. Open Market Analysis.
9. Open Data Explorer.
10. Download the filtered CSV.
11. Open `Airbnb_Analysis.ipynb` and show the analysis/charts.
12. End with the conclusion and key findings.

## Suggested video title

Airbnb Data Analysis and Visualization — Project Demonstration
